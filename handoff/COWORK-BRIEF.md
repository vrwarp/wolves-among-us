# COWORK HANDOFF BRIEF
## Print production for "Among Us: Footprints Edition"

**You are producing the physical prep materials for a youth-group game night.**
Everything is print-only. No code ships. No app is built.

**Attach these files alongside this brief — they are your source of truth:**
- `among-us-footprints-playbook.md` — full game rules, counselor roles, building layout
- `task-cards-16-groups.md` — the 16 task groups and master distribution

**Audience:** ~20 students, grades 6–12, plus 4 adult counselors.
**Constraint:** every student must be able to complete any task with **no phone**.

## 2. INDEX CARDS — 16 groups

Source the exact task lists from `task-cards-16-groups.md`. Do not invent or reorder them.

**Each card must show:**
- Group number, large, top-right corner
- Each task as a row: task name · where to find it · point value · an empty stamp box
- Stamp box: minimum 0.75in square, thick border, plenty of white space — a counselor stamps this while standing up
- Bonus strip at the bottom: `Bead name 5 · Bottle flip 3 · Sharp shooter 3`
- A `MY TOTAL: ___ / 10` line
- The reminder: `Your card is worth 16. You only need 10. You pick.`

**Layout:** 4in × 6in, two per Letter page, with cut lines. Cardstock.

**Acceptance:** all 16 cards total exactly 16 points. Verify programmatically and report the check.

## 3. SUDOKU AND MAZES

### 4×4 Sudoku — produce 20
- Numbers 1–4 only, 4×4 grid with 2×2 boxes
- **4 to 6 squares pre-filled**
- **Exactly one valid solution** — verify each puzzle by solver and report the count
- Grid must be at least 2.5in square; a 6th grader writes in it with a pencil
- 4 puzzles per Letter page
- Separate answer key page, puzzles numbered to match

### Mazes — produce 20
- Difficulty target: **a 6th grader solves it in 10–20 seconds.** This is a 3-point medium task, not a brain-teaser. Small grid, few dead ends. When in doubt, make it easier.
- Clear START and END markers
- At least 2.5in square, 4 per page
- Separate solution key

## 4. VERSE-SEQUENCING BAGS

**Mechanic:** a student gets a Ziploc bag of verse slips in scrambled order. They lay them out in correct narrative order. Each slip has a single character in the bottom-right corner. Correct order spells a code. They write the code on their index card. A counselor checks it against a key.

**Produce 4 different bag sets — A, B, C, D.** Different stories, so four different codes are in circulation.

**Recommended default (get approval first):** Romans Road — Romans 3:23, 6:23, 5:8, 10:9, 10:13. It fits the deck's existing theme, Romans 6:23a already appears on slide 41, and the 5-verse order is canonical and unambiguous.

**Per bag:**
- 5 slips, each with one verse, printed on cardstock, large text
- Each slip carries **one character** bottom-right, boxed
- **The code must be a random meaningless string** — e.g. `XK4RB`, never a real word. If it spells something, a student reads two slips and guesses the rest without reading the verses.
- Avoid confusable characters: no `I`/`1`, no `O`/`0`
- Bag label A/B/C/D printed on every slip in that set, so a counselor can tell which key to check against

**Quantity:** 3 physical copies of each set = 12 bags total.

**Deliver:** a key page listing bag → correct verse order → resulting code.

## 6. GOSPEL & THEME CARDS

The task is: find a question card, take the matching answer card, hand the pair to a counselor. 1 point.

Build the content on the D2S GOSPEL acrostic already in the deck:
- **G** — God created us to be with Him
- **O** — Our sins separate us from God
- **S** — Sins cannot be removed by good deeds
- **P** — Paying the price for sin, Jesus died and rose again
- **E** — Everyone who trusts in Him alone has eternal life
- **L** — Life with Jesus starts now and lasts forever

Produce **12 question/answer pairs** — two per letter. Questions should be answerable by a 6th grader who just heard the acrostic. Keep answers to one sentence.

Print questions and answers on visibly different colored stock so a counselor can see at a glance that a student handed over a matched pair. 6 cards per page, cut lines.

### Role cards — 4 different, one page each, large type

**Note for the Roaming Referee card:** this counselor walks the building loop continuously and never stands still — standing in the upstairs center area makes the whole second floor safe and kills the game.
